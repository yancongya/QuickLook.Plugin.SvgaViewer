QuickLook 内置的轻量播放器无法处理旧版 1.x ZIP 格式。选中文件按空格，本想核对动效，却可能只看到空白画面。

先装本体，再装插件

SvgaViewer 为 Windows QuickLook 增加 SVGA 支持。请先安装、启动 QuickLook，再打开插件安装包。

  1. 安装 QuickLook 4.x，并保持运行。
  2. 从 SvgaViewer Releases 下载 .qlplugin。
  3. 选中安装包，按空格，点击安装。
  4. 重启 QuickLook，选中 .svga 文件后按空格。

安装与开始使用

先装 QuickLook 本体，
再装 SvgaViewer 插件。

SvgaViewer 是插件，需要 QuickLook 本体提供空格预览窗口。第一次使用，请先安装并运行 QuickLook。

QuickLook 本体 → SvgaViewer 插件
  1. 1

    安装 QuickLook 本体

    下载 Windows 版 QuickLook，安装并启动，确认它正在系统托盘运行。

    下载 QuickLook 本体 ↗
  2. 2

    下载 SvgaViewer 插件

    从 SvgaViewer Releases 获取 .qlplugin 文件；源码 ZIP 不是插件安装包。

    下载最新版 .qlplugin ↓
  3. 3

    选中安装包，按空格安装

    保持 QuickLook 运行，在资源管理器中选中 .qlplugin，按空格，在弹出的窗口中点击安装。

    Space → 安装
  4. 4

    重启 QuickLook，开始预览

    安装完成后重启 QuickLook。选中任意 .svga 文件，再按空格即可预览动画。

开始之前，你可能想知道

需要先安装 QuickLook 吗？

需要。SvgaViewer 是 QuickLook 4.x 的插件，需要配合 QuickLook 使用。

支持 macOS 吗？

此插件面向 Windows 10/11，不是 macOS 的 Quick Look 扩展。

导出的 PNG 保存在哪里？

当前帧导出的 PNG 会保存在 SVGA 文件旁边。
