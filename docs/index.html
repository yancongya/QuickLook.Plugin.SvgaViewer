为什么做 SvgaViewer

看一眼 SVGA，原本没那么顺手

SVGA is a high-performance cross-platform animation format widely used in mobile apps. But QuickLook's ImageViewer uses SVGAPlayer-Web-Lite, which doesn't support 1.x format well, often showing blank preview or incorrect header check errors:

官方 ImageViewer 的局限Uses SVGAPlayer-Web-Lite, doesn't support 1.x format (ZIP), shows blank or error on preview
QuickLook Repo ↗
版本兼容性问题SVGA 1.x uses ZIP compression, 2.x uses zlib format, different file headers require different decoding
SVGA Website ↗
开发调试不便Designers and developers need to frequently verify exported SVGA animations, but lack convenient local preview tools
SVGAPlayer-Web ↗
⎵
SvgaViewer lets you play, inspect and export animations directly in ExplorerUses original SVGAPlayer-Web (supports 1.x + 2.x), loads JSZip for 1.x ZIP format, sets Priority=10 to override official ImageViewer
完整版本支持Supports both SVGA 1.x (ZIP) and 2.x (zlib) formats.
为检查而生Play, pause, seek, volume control and background inspection in one place.
需要时导出Save current frame as PNG, file stays in original directory.

SvgaViewer for QuickLook⊞Build from Source

Windows 10/11 · QuickLook 4.x · WebView2 Runtime · GPL-3.0

安装只需三步

  1. 1
    下载插件

    Get .qlplugin file from GitHub Releases.

  2. 2
    空格安装

    Select the file in Explorer, press Space, click "Install" in QuickLook preview.

  3. 3
    重启即用

    Restart QuickLook, go to any .svga file, press Space to preview animation.

从源码二次开发

SvgaViewer is an open-source .NET plugin. Welcome to modify playback logic, extend export formats or port to other platforms.

前置要求

  • Windows 10 / 11
  • QuickLook 4.x
  • WebView2 Runtime (usually pre-installed)
  • .NET SDK

克隆并构建

git clone .../QuickLook.Plugin.SvgaViewer.git
cd QuickLook.Plugin.SvgaViewer
dotnet build -c Release

打包为 .qlplugin

powershell -ExecutionPolicy Bypass `
  -File Scripts/build.ps1

Output is .qlplugin, install back to QuickLook to verify.

项目结构

Plugin.cs                  # IViewer Entry
SvgaViewerPanel.xaml(.cs)  # WebView2 Player Panel
Resources/Web/             # SVGAPlayer-Web / JSZip / Player UI
Samples/                   # Sample SVGA files for testing
Scripts/                   # Build script (build.ps1)
*.csproj / *.sln
