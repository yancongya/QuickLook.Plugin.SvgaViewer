为什么做 SvgaViewer

看一眼 SVGA，原本没那么顺手

SVGA 是移动端广泛使用的高性能跨平台动画格式。但 QuickLook 自带的 ImageViewer 用的是 SVGAPlayer-Web-Lite，对 1.x 格式 支持不佳，经常出现空白预览或 incorrect header check 报错：

官方 ImageViewer 的局限使用 SVGAPlayer-Web-Lite，不支持 1.x 格式（ZIP），预览时空白或报错
QuickLook 仓库 ↗
版本兼容性问题SVGA 1.x 用 ZIP 压缩、2.x 用 zlib 格式，文件头不同需要不同的解码方式
SVGA 官网 ↗
开发调试不便设计与开发同学要频繁校验导出的 SVGA 动画，却缺少顺手的本地预览工具
SVGAPlayer-Web ↗
⎵
SvgaViewer 让你在资源管理器里直接播放、检查并导出动画使用原版 SVGAPlayer-Web（支持 1.x + 2.x），1.x ZIP 自动加载 JSZip，设置 Priority=10 覆盖官方 ImageViewer
完整版本支持同时支持 SVGA 1.x（ZIP）与 2.x（zlib）格式。
为检查而生播放、暂停、拖拽定位、音量与背景检查集中在一处。
需要时导出将当前画面保存为 PNG，文件仍留在原目录。

SvgaViewer for QuickLook⊞从源码构建

Windows 10/11 · QuickLook 4.x · WebView2 Runtime · GPL-3.0

安装只需三步

  1. 1
    下载插件

    从 GitHub Releases 获取 .qlplugin 文件。

  2. 2
    空格安装

    在资源管理器中选中该文件，按 空格，在 QuickLook 预览窗里点击「安装」。

  3. 3
    重启即用

    重启 QuickLook，回到任意 .svga 文件，按 空格 即可预览动画。

从源码二次开发

SvgaViewer 是开源的 .NET 插件，欢迎基于它修改播放逻辑、扩展导出格式或移植到其他平台。

前置要求

  • Windows 10 / 11
  • QuickLook 4.x
  • WebView2 Runtime（通常已预装）
  • .NET SDK

克隆并构建

git clone .../QuickLook.Plugin.SvgaViewer.git
cd QuickLook.Plugin.SvgaViewer
dotnet build -c Release

打包为 .qlplugin

powershell -ExecutionPolicy Bypass `
  -File Scripts/build.ps1

产物为 .qlplugin，装回 QuickLook 即可验证。

项目结构

Plugin.cs                  # IViewer Entry
SvgaViewerPanel.xaml(.cs)  # WebView2 Player Panel
Resources/Web/             # SVGAPlayer-Web / JSZip / Player UI
Samples/                   # Sample SVGA files for testing
Scripts/                   # Build script (build.ps1)
*.csproj / *.sln
