为什么做 SvgaViewer

看一眼 SVGA，原本没那么顺手

SVGA 是一种高性能的跨平台动画格式，广泛用于移动端应用的动效展示。但官方 QuickLook 的 ImageViewer 使用 SVGAPlayer-Web-Lite，对 1.x 版本 的 SVGA 文件支持不佳，常出现空白预览或 incorrect header check 错误：

官方 ImageViewer 的局限使用 SVGAPlayer-Web-Lite，不支持 1.x 格式（ZIP 格式），预览时出现空白或错误
QuickLook 仓库 ↗
版本兼容性问题SVGA 1.x 使用 ZIP 压缩格式，2.x 使用 zlib 格式，两者文件头不同，需要不同的解码方式
SVGA 官网 ↗
开发调试不便设计师和开发者需要频繁确认导出的 SVGA 动画是否正确，但缺少便捷的本地预览工具
SVGAPlayer-Web ↗
⎵
SvgaViewer 让动画直接在资源管理器中播放、检查与导出使用 SVGAPlayer-Web 原版（支持 1.x + 2.x），加载 JSZip 库处理 1.x ZIP 格式，设置 Priority=10 覆盖官方 ImageViewer
完整版本支持同时支持 SVGA 1.x（ZIP 格式）和 2.x（zlib 格式）。
为检查而生播放、暂停、进度条、音量控制和背景检查集中在一处。
需要时导出将当前画面保存为 PNG，文件仍留在原目录。

SvgaViewer for QuickLook⊞从源码构建

Windows 10/11 · QuickLook 4.x · WebView2 Runtime · GPL-3.0

安装只需三步

  1. 1
    下载插件

    从 GitHub Releases 获取 .qlplugin 文件。

  2. 2
    空格安装

    在资源管理器中选中该文件按 空格，在 QuickLook 预览窗里点击「安装」。

  3. 3
    重启即用

    重启 QuickLook，回到任意 .svga 文件按 空格 即可预览动画。

从源码二次开发

SvgaViewer 是开源的 .NET 插件，欢迎基于它改播放逻辑、扩展导出格式或移植到其他平台。

前置要求

  • Windows 10 / 11
  • QuickLook 4.x
  • WebView2 Runtime（通常已预装）
  • .NET SDK

克隆并构建

git clone .../QuickLook.Plugin.SvgaViewer.git
cd QuickLook.Plugin.SvgaViewer
dotnet build -c Release

打包为 .qlplugin

powershell -ExecutionPolicy Bypass `
  -File Scripts/build.ps1

产物为 .qlplugin，装回 QuickLook 即可验证。

项目结构

Plugin.cs                  # IViewer 入口
SvgaViewerPanel.xaml(.cs)  # WebView2 播放面板
Resources/Web/             # SVGAPlayer-Web / JSZip / 播放器 UI
Samples/                   # 测试用 SVGA 示例文件
Scripts/                   # 打包脚本（build.ps1）
*.csproj / *.sln
