项目将 .NET 宿主与 SVGAPlayer-Web WebAssembly 播放器分开。你可以修改播放器界面、调整播放交互，或扩展宿主逻辑，再在 Windows 的 QuickLook 中验证。

QuickLook.Plugin.SvgaViewerPlugin.csQuickLook 预览入口SvgaViewerPanel.xaml.csWebView2 宿主桥接Resources/Web/播放器界面 · SVGAPlayer-Web · WASMSamples/ · Scripts/示例文件与打包脚本
获取源码 → 构建 → 打包
# Clone
git clone https://github.com/yancongya/QuickLook.Plugin.SvgaViewer.git
cd QuickLook.Plugin.SvgaViewer

# Build
dotnet build -c Release

# Package on Windows
powershell -ExecutionPolicy Bypass -File Scripts/build.ps1

需要 Windows 构建环境与 .NET Framework 4.6.2 目标框架支持。打包后，将 .qlplugin 装回 QuickLook 验证。
